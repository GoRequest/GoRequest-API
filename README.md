# GoRequest

GoRequest is an open-source API testing tool built with **Go** and **React**.

The goal is to provide a simple and intuitive way to send HTTP requests, inspect responses, and debug APIs directly from your browser.

This project is also an opportunity to explore HTTP, networking, and backend development with Go.

## Features

The following features are planned:

- Support for GET, POST, PUT, PATCH, and DELETE requests
- Custom request headers and body
- JSON request and response visualization
- HTTP status codes and response times
- Authentication using Bearer Tokens
- Request history and collections

## Tech Stack

- **Backend:** Go
- **Frontend:** React + TypeScript
- **Communication:** HTTP/REST
